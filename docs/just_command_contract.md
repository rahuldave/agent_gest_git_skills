# Just command contract

The just command contract moved to the jnterfaces package. Its source is
`.agents/skills/just/references/command_contract.md` in
https://github.com/rahuldave/jnterfaces. The `just` skill of that package also
gives the house style of a Justfile and the Justfile templates.

In a repository that has jnterfaces installed, read
`.agents/skills/just/references/command_contract.md`. The labs of this
repository, for example `just agentic-target-lab`, still check the protocol
rules that the contract describes.
