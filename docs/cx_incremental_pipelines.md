# cx incremental builds and pipelines

The cx guidance moved to the jnterfaces package. Its source is the `cx` skill,
`.agents/skills/cx/SKILL.md`, and its worked examples are in
`.agents/skills/cx/references/incremental_pipelines.md` in
https://github.com/rahuldave/jnterfaces.

The recipe `just cx-examples-lab` of this repository still runs the artifact
pipeline and the incremental C build that the examples describe.
